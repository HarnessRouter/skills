# HarnessRouter Skills

Official Agent Skills for building agent-powered products with
[HarnessRouter](https://harnessrouter.ai).

## Available Skill

- [`harnessrouter`](./harnessrouter): identify agent-powered product features, plan Workspace and
  Harness boundaries, configure instructions/Tools/MCP/Skills, integrate the runtime, handle
  Streaming/Sessions/Files/Artifacts, and test the complete product path.

Install or load the Skill using the GitHub Skill mechanism supported by your coding-agent
environment, then invoke `$harnessrouter` while building or modifying the product.

Exact API endpoints, fields, limits, and capabilities are governed by the deployed HarnessRouter
API schema. If this repository and the deployed API disagree, follow the deployed API and report
the documentation drift.
